Read CLAUDE.md. Every result over a health, operational or aesthetic limit in the last year, and whether an event covers it.

Run `npm run water -- exceedances`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Any health result with event "NO" is the first thing to raise.
